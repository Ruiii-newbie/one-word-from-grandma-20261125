# One Word From Grandma

[![make.fun · u-0xkianno-one-word-from-grandma-f04bed16](https://make.fun/badge/u-0xkianno-one-word-from-grandma-f04bed16.svg)](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16)

Entry for make.fun's "One Word From Grandma" bounty ($5 in USDC).

## The entry

One word, and nothing else:

```
voodoo
```

The word Grandma would text about AI. She does not know what a neural
network is and does not want to know — the phone listens, then answers
back, and it knows things nobody told it. There is exactly one word in
her world for a box that talks back and knows things it should not
know: voodoo. Probably sent at 6 in the morning, probably with no
context at all.

## Run it

```sh
python3 main.py
```

It prints exactly one word, `voodoo`, followed by a newline. No
arguments, no network, no files read or written.
